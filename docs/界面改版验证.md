# Spin Space Group Database 界面改版验证

本版保留项目原有五层分类、17 种类型和 67,475 个 Xiao 对应条目，仅借鉴参考数据库的呈现方式；未采用其分类体系。

1. 对 51 个母群的 5,365 个受影响名称重新用 LaTeX 编译空间反演及旋转反演的横线，逐项确认除横线表示外公式未变化；67,475 个名称的 SVG 与公式哈希逐一回读。名称和底层表示数据未改动。
2. Q 和 K 节点去除居中点，连续族节点不再添加“一般参数”前缀。
3. 移除界面中无关的提示文字、分类数量横幅和离线状态横幅。
4. 顶层窗口使用 Spin Space Group Database 名称，不再显示原有大标题。
5. 自动展开层级移至设置菜单。
6. 数量列可在设置中开关；结果列表及分页可折叠、展开。
7. 检索结果和群详情已分为独立窗口，分页仅属于检索结果。由于两个窗口不再共享布局，原来位于它们之间的同窗分隔线不再存在；可分别移动和调整两个窗口。
8. Xiao 编号位于独立的“标签检索”区域，与“条件检索”分开。
9. 结果列依次为自旋构型、Spin-lattice type、SSG name、Q、K、Xiao 编号和参数；Q 的下标使用预编译数学公式。
10. 共线、共面、非共面按顺序显示；各分页和特殊条件分支采用相同排序。
11. `kχ=0` 使用 LaTeX 预编译的矢量公式显示。
12. 移除第五层节点中“一般参数”前缀；特殊参数与一般值仍按数据库原有规则区别计算。
13. 移除逐级目录入口及相关界面代码。
14. 11,494 条 Type 2 记录均检查到已有波矢数据；第四层以保存的传播矢量代表代替 T 生成元字符串。分类归属及原有等价规则未改变。
15. 独立详情窗口以自旋矩阵、空间旋转、空间平移、自旋操作和空间操作分列展示。有限情况由有效表示的精确像计算 K ≅ G/kerρ 的元素代表，包含平移生成的陪集；与 Q=K/H 区分。跨 17 类标签及多个母群抽查 41 个有限例子，逐个核对群阶和代表的相容性。连续族显示参数化点操作和平移生成元；用户指定有理参数后使用精确相位闭包生成有限元素。N143.5.2、P1.5.1、P27.5.2 的 42 个代表逐项以精确代数数检验。
16. 删除可视化中的原始 JSON、内部哈希和群同构证书；分类与群操作保留在独立详情窗口。JSON 仍可由用户主动导出。

树形目录的叶节点与结果表的选中行同步。联合条件检索返回具体匹配代表时，群操作按该轨道代表自身的参数与自旋坐标计算；手动输入连续参数则使用名称所采用的规范代表，避免把两套参数混用。

数据库副本中，除 5,365 条 LaTeX 文本及相应 SVG 外，分类标识、名称字段、底层表示数据和分类归属均与原库逐条相同。公式资源共 67,475 条，逐条检查哈希及纯矢量输出。

连续族第五层仍保留原有精确符号表示；不同参数化是否达到全局最简归并不因本次界面重设计而得到新的证明。具体有理参数的群像超过 4096 个元素时，程序提示而不截断冒充完整表。
