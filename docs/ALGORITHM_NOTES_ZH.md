# 与原算法的对应及必要的实现处理

输入规范和算法流程以 `reference/algorithm.md` 为准，补充材料用于核对数学约定。附件内容是待实现的算法材料，不作为修改工作区权限、发送消息等操作指令。

## 保持的总体流程

先计算母群 extension 与 GF(2) 分级；按正规核枚举 Type 0；按波矢协变和 1-cocycle 枚举 Type 1；按不变 `t0` 和扭曲 GF(2) 枚举 Type 2。共线复用分级，共面 Type 1 复用非共面 Type 1，两个 V4 分支复用不变核与零化子。先去自旋共轭，再对成对的 `(rho,chi)` 做空间自同构去重，最后读取 17 类标签。

程序没有用有限平移周期截断替代连续波矢，也没有用“所有矩阵允许元素中随便找同态”替代 Type 0 正规核方法。

## 1. 实空间与倒空间坐标必须分开

MD 把整数 `R_p` 和波矢写在同一符号下。在原胞分数坐标中，实空间列向量变换为 `t -> R_p t`，倒空间列向量的主动变换为 `k -> R_p^(-T) k`。

由 `k·(R_p t)=eta_p k·t mod 1` 直接得到 `R_p^T k=eta_p k mod Z³`。程序按这条式子建立协变系统。对完整点群它与倒空间主动变换条件等价。Type 2 置换使用 `R_p^(-T)`，使置换矩阵及扭曲方程的逆指标一致。P3 的非正交原胞回归检验覆盖此问题。

## 2. Type 2 的 S3 需要保向提升

MD §5.4 与补充材料 II.F 同时要求 `D∈V4`（`det D=1`）、`rho=D*S∈SO(3)`，又把 `S` 称为普通置换矩阵。普通奇置换的行列式为 −1，按字面直接相乘会违反目标群。

采用

`S(sigma)=sign(sigma)*P_sigma`。

因为维数为 3，`det S=1`；而 `S(sigma)S(tau)=S(sigma*tau)`，故这是一个真正的 S3 到 SO(3) 的提升，不引入额外 factor system。它在对角 V4 上的共轭仍是相同的轴置换，所以 MD 的 `sum(theta_i)=0 mod 2π` 和原扭曲方程均原样成立。检验包含全部 36 对置换乘法及各输出矩阵的行列式。

## 3. SNF 零方向不能都算作物理连续参数

MD §5.3 的 Smith 段落没有显式写出连续 coboundary。相位变换为 `theta_p -> theta_p+(1-eta_p)c`。若 eta 非平凡，总有一个连续相位方向来自共轭，不是不同群。

选第一个 `eta_r=-1` 的代表，令 `theta_r=0`。任意相位都能用 `c=-theta_r/2` 达到；剩下 `c=1/2` 对所有相位的作用是整数，故不再产生重复。此后 SNF 得到的是模 coboundary 的解，而非原始 Z¹。`solve_h1_eta` 的 C2 反幺正分支只有一个离散类，而不是一个连续圆。

## 4. 连续波矢与相位联合求解

MD 分步描述先求波矢、再找特解、再加 H¹。程序提供这三个单独接口，同时主枚举联立相同方程求解 `(k,theta)`，以免把局部 H¹ 分支错误当成全局互不相连的族。

例：P21 的 eta=+ 分支满足 `2 theta_s=k_y mod 1`。完整解为 `k_y=2u, theta_s=u`，`u∈R/Z`。固定 k 时有两个相位分支，但随 k 绕一周它们交换。联合 SNF 自动保留这一覆盖结构。

## 5. 特殊点与标签

Type 1 明确排除 k=0，程序将它交给 Type 0。对每个连续解环面求 `2k=0 mod 1` 的全部交集，生成非零 TRIM 的独立记录；一般分支排除这批点。这样不会给同一族中落在 TRIM 的点误标为 N.1.2/P.1.2。

一般分支是一个连通解环面删去特殊点的参数域。删点后参数域可能不连通，当前记录表示这个带排除条件的域；不声称已经划成所有拓扑连通开区间。完整的参数关系仍给出正确商空间。

## 6. 共面 V4 必须遍历三种无序波矢对

MD §5.7 的“零化子中的两个非零 TRIM”解释为遍历所有三种无序选择，不能任意取一次。补充材料 III.A.4 明确指出每个核有三种不等价平移 holonomy，因为法向与面内方向不能交换。因此 P1 有 7×3=21 个共面 V4 平移类；D1 另有 7 个。

## 7. 自同构生成元与无限参数作用

MD 把 Out⁺(G) 列为输入。程序检查给定自同构，但不通过一个任意整数矩阵截断宣称求得全部 Out⁺(G)。P1 的 Out⁺ 是 SL(3,Z)，给出六个初等变换生成元即可完整表示它。

空间作用可以在有限“族目录”上求轨道，但这不表示一个族内部的所有参数都等价。程序保存生成元诱导的参数关系，而非输出一张假装穷尽连续点的有限代表表。默认未传自同构时结果标为 `spin_only`；一般输入生成元时标为 `provided_generators`。

## 8. 对照材料能检验到什么

补充材料给出 17 类定义、若干平移 holonomy 数量与结构论证，没有提供本包所枚举每个母空间群的完整计数基准表。因此检验包括类型覆盖、P1 的 7/21 数量、已知有限商、穷举小群、全部定义关系、连续商关系以及安装后运行；不能称为“与 230 个母群完整计数表逐项一致”。

外部核对仅用于工具和自同构背景，不替代附件算法：[SymPy 整数矩阵标准形](https://docs.sympy.org/latest/modules/matrices/normalforms.html)、[IUCr normalizer 定义](https://dictionary.iucr.org/Normalizer)。


## v0.2：完整空间作用与用户指定的族口径

新增 `normalizers.py` 自动构造全部三维母群的完整保向仿射正规化子作用，主函数选择 `automorphisms="full"`。证明见 [NORMALIZERS_ZH.md](NORMALIZERS_ZH.md)。空间群扩张类必须取完整有限轨道的 Schreier 稳定子，不能只逐个过滤点群正规化子生成元。含心晶格的本征格耦合、行列式为正的核及原点平移分量均已处理。

按用户后续明确要求，删除特殊点后的整个连续参数域计作一族，故不作连通区间计数。历史审计提出的“拆分删点后的连通分支”已撤销。
