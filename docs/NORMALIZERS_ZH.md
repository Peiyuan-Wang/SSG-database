# 三维空间群完整保手征自同构：算法与完备性

本实现计算保持晶格的完整保向仿射正规化子在自旋共轭类上的作用。原胞晶格是 `Z³`，空间群由 `(R_p,tau_p)` 给定。仿射坐标变换 `(A,o)` 满足

```
A ∈ SL(3,Z)
A R_p A⁻¹ = R_phi(p)
A tau_p + (I-R_phi(p)) o - tau_phi(p) ∈ Z³.
```

算法输出有限生成元，不枚举无限多个自同构。每个返回生成元都独立验证所有乘法表和 2-cocycle 等式。`complete=True` 的依据是下列构造的完备性，而非“候选都通过验证”。

## 1. 点群的完整整数正规化子

先计算点群不变实对称二次型空间的维数 `d`。三维晶体点群只出现 `d=6,4,3,2,1`，对应五种可穷尽的实表示结构。

| d | 结构 | 完整算法 |
|---|---|---|
| 6 | 三个相同的一维实表示，点群包含于 `{I,-I}` | 六个初等整数切变及一个反射生成 `GL(3,Z)` |
| 4 | 同一一维表示出现两次，另有一个不同的一维表示 | 在二维本征平面与一维本征轴的饱和整数基底上用 `GL(2,Z)×{±1}`，再精确取原晶格的稳定子 |
| 3 | 三个不同的一维实表示 | 正规化子必置换三条有理本征轴；枚举原始轴向量的 48 个带符号置换，保留整系数且确实正规化点群的元素 |
| 2 | 不可约二维平面加不同的一维轴 | 完整枚举一个不变正定二次型的整系数等距群，再筛点群正规化子 |
| 1 | 不可约三维表示 | 同上 |

`d=4` 时令 `C` 的列是两个饱和本征晶格的基，`D=|det C|`，父晶格在此基底下为 `Λ=C⁻¹Z³`。它包含 `Z³`，并包含于 `(1/D)Z³`。`GL(2,Z)×{±1}` 作用后仍满足此包含关系，所以晶格轨道有限。用 `HNF(D t C⁻¹)` 作精确轨道键，遍历全部轨道和生成元边；对每条边保留 Schreier 元 `t_y⁻¹ s t_x`。变回原胞基底后得到完整稳定子。不能忽略含心晶格中平面与轴的耦合。

`d=1` 时不变二次型唯一至正比例；正规化子作用保持这个射线，而整系数可逆矩阵的行列式绝对值为 1，故比例为 1。`d=2` 时两个不可约子空间维数不同，各自必须保持；各自与晶格的交是满秩晶格，因此限制的行列式绝对值也为 1，分别保持两块的不变二次型。于是完整正规化子都保持

```
Q = Σ_p R_pᵀ R_p.
```

对矩阵第 j 列 `v`，条件 `vᵀQv=Q_jj` 给出精确界 `v_i² ≤ Q_jj (Q⁻¹)_ii`。程序据此枚举全部整数列，再检查列间内积。界依赖输入基底，没有人为指定“小整数矩阵范围”。

## 2. 保手征子群

对 `det: N_GL(3,Z)(P) → {±1}` 取核。存在反向生成元时，使用指数二 Schreier 算法，陪集代表取 `I` 与任意一个反向元。**不直接删掉反向生成元**：两个反向元素的乘积可能提供必需的保向生成元。

## 3. 空间群扩张类的稳定子

线性正规化子可能把空间群送到具有相同点群的另一个扩张，因此不能只保留原生成元中恰好可提升的几个。

把 section 平移按点群索引堆成 `tau∈(R/Z)^(3|P|)`，令 `B` 堆叠 `(I-R_p)`。改变原点产生 `tau→tau+B o`。求 `B` 的整数左零化子基 `C₀`，则

```
extension_key(tau) = C₀ tau mod 1
```

完整刻画 section 数组模原点移动的商：整数零化子是饱和的，恰为连通子环面 `im B` 的全部特征标。输入平移有理，整数线性作用不增加其公共分母，因此扩张类轨道有限。

在完整保向点群正规化子生成元及逆元下遍历**全部**扩张类轨道。每条边 `s t_x→t_y` 产生 `h=t_y⁻¹ s t_x`，这些元素生成完整扩张类稳定子。对每个 h 用 Smith 分解解

```
B o = tau - h·tau mod 1,
```

取一个精确有理原点作为仿射提升。空间群 Pc 的轨道大小为 3，是必须使用“轨道稳定子”而非“逐生成元过滤”的回归例子。

## 4. 补齐原点平移核

再次精确求解 `B o=0 mod 1`，加入全部离散环面分量的代表。连续方向满足 `B v=0`，逐点中心化母群，作用平凡，可以省略。整数原点平移诱导母群内部的平移共轭；表示中的作用是整体自旋共轭，所以在自旋去重后也可省略。

因此选定线性提升与全部原点核代表生成完整需要的作用，模掉的是已证明作用平凡的变换。P-1 的原点核恰有 8 个分量；只算 SL(3,Z) 而不加这些原点移动会漏合并。

## 5. 作用于 SSG 的方式

空间生成元同时作用于 `rho` 与 `chi`，不能先分别取轨道再任意组合。对 Type 1：

```
k' = Aᵀ k
theta'_p = theta_phi(p) + k·u_p
```

随后重置自旋相位规范。精确比较完整参数环面的整数约束与整体反号，计算参数关系 `M u + N v = b mod 1`。对有限图册索引用并查集取得轨道；无限连续参数作用仍保留为生成关系。

性能上把 `rho×chi` 的生成元作用分别缓存，但最终合并的键仍包含两者。相同表示不会为每个分级重复作 Smith 分解。这是计算复用，不改变联合等价关系。

## 6. 连续族计数约定

遵照用户明确要求，同一个 Smith 参数域删去零波矢和 TRIM 后仍是一族，即使删点后断成多个区间。不按区间数增加分类数。

例如 P41 轴向族 `k=(0,0,4u)`、`theta=(0,u,2u,3u)` 删除 `u=j/8` 后剩余的八个区间总共计一族。特殊点分别进入 Type 0 或 TRIM 记录。另一个位于 `(1/2,1/2,k_z)` 的参数域是不同的 Smith 分量，只有存在实际自旋/空间等价才会合并。

同族不意味着所有参数点都是同一个具体群。程序保留精确参数关系；有理点轨道可有限穷尽，一般无理点的自动成员判定无法决定时返回 `unknown`。这一点不影响用户所要求的族分类计数。

## 7. 可复核的检查

- 230 个标准母群均计算完整生成元并验证 cocycle 恒等式。
- 有限点正规化子阶：P222 48、P3 24、P41 16、P23 48、P432 48；保向子群精确等于其中行列式为正的全部元素。
- 对 P3 作非正交整数换基，所得正规化子严格等于原正规化子的共轭，包含绝对值大于 1 的矩阵元。
- 含心单斜群 5、8、9、12、15 检查本征晶格指数与完整有限晶格轨道。
- P1 恢复 17 类（L/P/N=2/5/10），P-1 恢复 35 类（3/9/23）。
- P41 对全部八个被删点测试拒绝，对八个剩余区间各取一个精确有理点验证属于同一参数域；采样只用于回归检查，分类本身由精确模方程决定。
