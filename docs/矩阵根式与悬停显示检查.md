# 矩阵根式与悬停显示检查

## 问题和修复

群操作表使用专门的矩阵绘制器。旧版悬停提示另外使用 `⎛、⎜、⎝` 等分段字符拼接括号，系统提示框的字体和行距不能保证这些字符相连，因此看起来像破碎的括号。提示框现在以等宽、对齐的独立矩阵行显示原始精确值，例如 `[ −1, 0, 0 ]`；根式在文字提示中以 `sqrt(...)` 明确表示。表格本身继续以数学根号显示。

此外，嵌套根式中的内外横线过去可能重叠。现在根据嵌套层级确定横线高度，并为矩阵行增加相应空间。相邻因子的间隔也得到保留，避免相邻根号粘连。

符号矩阵原来可能先去掉乘号，再识别 `pi` 和 `u0`，使 `2*pi*u0` 被错误显示成 `2piu0`。现先识别 π 和参数下标，再整理乘号；例如 `cos(2*pi*u0)` 显示为 `cos(2πu₀)`。

## 本次检查

- 扫描完整数据库的 67,475 个分类，将非轴向有限群归并为 620 组不同的自旋生成元集合，检查其闭包中的 8,401 个矩阵；其中遇到的根式均可被显示解析器完整识别。
- 轴向自旋的常数相位分母和数据库波矢偏移分母的最小公倍数为 12；对单个有理参数分母不超过 48、结合这些常数相位得到的 4,584 个不同相位，检查其正弦和余弦输出。涉及的 68 种不同根式表达式中，未发现解析器遗漏 `sqrt(...)` 的情况。
- 生成上述根式表达式的渲染图，以及包含普通根式、乘积和多层嵌套根式的矩阵预览；检查了截图中涉及的 P40.5.4 的实际悬停提示及不同缩放下的界面。
- 回归测试覆盖根号数量、嵌套层数、矩阵行高、轴向符号、悬停文本和具体群的参数计算；Mac 版 150% 缩放测试也已运行。

可使用 `python scripts/audit_matrix_radicals.py <数据库路径> --output <报告路径>` 重新执行目录生成元与有限相位的解析检查。

## 范围

上述解析检查覆盖所列有限数据集合。它不能证明任意多参数的所有有理数组合、用户输入构造的任意复杂表达式、未来新增数据或每一种操作系统和显示缩放下的视觉结果。矩阵表中出现超长表达式时仍需横向滚动；Mac 上的截图检查不等于 Windows 桌面人工检查。
