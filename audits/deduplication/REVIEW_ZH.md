## 一、逐层审计结果

| 层次 | 已实现的内容 | 缺口 / 审计结论 |
|---|---|---|
| 自旋空间共轭 | Type 0 正规核/像；Type 1 连续相位规范及整体反号；Type 2 同时作用于全部平移与 section 的符号置换 | 有实际算法。独立小群矩阵检验未发现残余重复，不能仅由总数偏大推断这一层全错；尚不能用同态验证代替完备性证明 |
| 连续参数分类 | 联合 Smith 解空间；整数子环面规范形式；零点/TRIM 排除条件；参数关系 | 未分解删除特殊点后断开的参数域；也没有独立的“族—类型层—空间轨道”计数对象。当前正维图册数不是连通族数 |

代码位置：

- `census.py` 的 `_worker` 调用 `enumerate_ssg(group, automorphisms=None, verify=True)`，随后直接对返回记录计数。
- `type1.py` 的 `split_type1_strata` 对每个正维环面只加入一个 `general` 记录；`.point()` 虽然排除 TRIM，却不把删点后的域拆成连通分支。
- `deduplication.py` 的 `deduplicate_automorphisms` 依赖调用方提供生成元；空列表不能代表已经模去 Out⁺。
- `validation.py` 的 `validate_representation` 检验同态定义关系。它不检查代表间是否等价，更不证明外自同构生成元完整。

## 二、空间去重缺失：本包实际复算的证据

对 P1 与 P-1 可以明确写出完整保向仿射正规化子的作用，不需要猜测矩阵截断。

- P1：线性部分是 SL(3,Z)，任意原点平移作用平凡。六个初等加行变换生成全部线性作用。
- P-1：反演的 section 可取零；任意 A∈SL(3,Z) 都正规化反演，原点条件恰为 `2o∈Z³`。因此再加入三个半格原点平移即可生成完整作用。

对同一批本包生成的记录，得到：

| 母群 | 仅自旋去重 L/P/N | 加完整空间作用后 L/P/N | 图册轨道总数变化 |
|---|---|---|---|
| P1 | 8 / 37 / 128 | 2 / 5 / 10 | **173 → 17** |
| P-1 | 16 / 137 / 832 | 3 / 9 / 23 | **985 → 35** |

这些数字仍是带类型分层的图册轨道，不是把连续族内部所有参数点都认定为同一个群。它们足以证明：230 群统计缺失的空间步骤会保留大量应合并的记录，不能用上一轮数字替代最终分类。

可复算脚本：[audit_spatial_examples.py](audit_spatial_examples.py)。结果：[spatial_examples.json](spatial_examples.json)。

## 三、连续层的具体缺口：P41 的轴向分支

本包实际输出的 eta=(1,1,1,1) 轴向解是

```
k=(0,0,4u) mod Z³
theta=(0,u,2u,3u) mod Z⁴
u∈R/Z
```

这张图册表示一个四重覆盖，不能丢弃相位分支信息。

1. Type 1 必须去掉 k=0。对应 `u=0,1/4,1/2,3/4`；圆删去四点后有 **4 个开区间**。自旋反号 `u→-u` 把它们两两交换，剩 **2 个连通分支轨道**。
2. 当前 `general` 记录进一步排除全部 TRIM，即 `u=j/8`。圆删去八点后有 **8 个开区间**；仅模自旋反号后剩 **4 个一般层连通分支轨道**。
3. 当前程序却把这一整张穿孔图册计作 **1 个连续项**。

所以连续层不是一个简单“再把数字除小”的问题：它既可能把特殊点单列而增加目录项，也可能把断开的参数域合计为一项而漏算连通分支。必须先定义要数的是完整族、固定 17 类型的连通层，还是参数点的精确等价类。

上述区间数是精确拓扑分解，不是网格采样；`u→-u` 精确把区间 j 映到区间 `n-1-j`。这里只审计自旋商前后的域，尚未加入 P41 的完整空间自同构，不能把 2 或 4 当成 P41 的最终总数。

结果：[continuous_domains.json](continuous_domains.json)。

## 四、自旋共轭层的独立核查

对 P1、P2、P21、P3 的非共面和共面离散表示，共检查 **307 个记录**。先用全部生成元矩阵的迹与行列式排除不可能等价的配对，对剩余 **287 对**候选，独立求解交织方程

`A_i X = X B_i`（所有晶格平移生成元和所有 point-group section 同时成立）。

若解空间含可逆 X，则对实正交表示，极分解给出正交交织矩阵。三维可通过 X 的整体反号选择 SO(3) 共轭；二维保留 O(2)。本检查没有调用标准形哈希作为最终等价判据。

结果：这组例子没有发现自旋去重后仍残留的等价配对。它支持现有自旋处理，但不证明 230 个母群的全部连续问题已经解决。

可复算脚本：[audit_spin_and_domains.py](audit_spin_and_domains.py)。结果：[spin_uniqueness.json](spin_uniqueness.json)。

## 五、修订后的三层算法规范

### A. 自旋共轭必须同时比较全部生成元

先固定平移 holonomy 的标准形，再使用它的残余正规化子；比较对象必须同时包含平移矩阵与 section 矩阵。非共面比较时还要求 chi 一致。不能分别对每个矩阵独立排序或共轭，也不能先分别对 rho、chi 做空间去重再随意组合。

- Type 0：晶体学有限像下使用正规核与像分类；保留实际同构与矩阵作证据。
- Type 1：先模 `theta_p→theta_p+(1-eta_p)c`，再模 `(k,theta)→(-k,-theta)`；反号作用须落实到实际参数域。
- Type 2：非共面使用 SO(3) 中的 V4 正规化子，共面只用 O(2) 中相应正规化子；对完整矩阵元组做同一次共轭。
- 小群以可逆交织矩阵独立复核；删除的记录应能追溯到明确等价证据。

### B. 连续层必须记录真实参数域与分支

1. 联立整数模方程并去规范，取得 `x=x0+B u mod 1`。这一步现有 Smith 模块可复用。
2. 将参数表示化为无冗余的原始环面坐标，避免覆盖参数自身产生重复。
3. 求零波矢、TRIM 与其他改变标签/稳定子的精确子集；明确它们是被排除、独立分层，还是作为族的边界保留。
4. 求实际域的连通分解。现有 Type 1 在去规范后固定波矢的纤维有限：一维环面删有限点必须拆成开区间；二维/三维环面删有限点不因此断开。不能只比较闭包的整数零化子。
5. 把自旋反号作用于完整分支；它可能交换两张图册，也可能交换同一闭包内的不同区间。
6. 保存 `family_id`、`stratum_id`、`domain`、参数识别关系与稳定子。统计分别命名 `family_count`、`stratum_count`、`orbit_count`，不要用一个 `len(records)` 代表全部含义。

非对称空间群的相位覆盖必须保留；闭合绕行导致分支交换的论证，只能在该绕行没有穿过被排除集合时使用。

### C. 空间层需要完整生成元，而不只是一个接收列表的函数

从保向仿射正规化子出发，对每个线性变换 A 求置换 phi 与原点 o，使

```
A R_p A^(-1) = R_phi(p)
A tau_p + (I-R_phi(p)) o - tau_phi(p) ∈ Z³
det A = +1
```

必须证明生成元覆盖全部允许作用。固定小整数矩阵范围只是一种候选搜索，不能证明完整性。若从含反向生成元的完整群取得保向子群，应计算行列式同态的核；不能简单丢掉所有负行列式生成元，因为负生成元的乘积可能生成新的保向作用。

对每个生成元同时变换

```
k'       = A^T k
theta'_p = theta_phi(p) + k·u_p
kchi'    = A^T kchi
chi'_p   = chi(u_p s(phi(p)))
```

然后重新规范化自旋，并作用于 B 步已分解的真实参数域。有限离散代表/连通层的轨道可用并查集，但族内参数关系必须继续保留，不能把轨道内所有参数点都当作同一个群。

## 六、什么检验才足以支持新统计

- 同态成立、生成元集合的完备性、代表互不等价是三种不同检查。
- P1、P-1 必须恢复本次明确的空间轨道合并。
- P21/P41 等螺旋群必须测试相位覆盖、被删除点及连通分支。
- 真实参数域而非仅闭包必须在每个群作用下闭合。
- 完成三个步骤后才能重新汇总 230 群。旧 CSV 的和式正确，仅证明统计程序没加错数，不证明分类已经完成。
