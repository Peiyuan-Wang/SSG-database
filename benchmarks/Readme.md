## 外推方法与限制

历史 230 个母群的任务耗时之和为 4012.743 秒。这是并行任务时长之和，不是单进程实测时长，也不是墙钟时间。当前样本计算时长/历史同组时长之比为 0.999。

模型一：计算部分按该比率校准，导出与回读按图册数外推；模型二：按样本总时长与历史任务时长之比外推。样本母群均直接代入实际时长，其余母群使用外推；按母群编号顺序模拟 4 个工作进程。模型墙钟估计分别为 28.5 分钟和 36.6 分钟。

样本有意包含慢群，并非随机样本；上述模型不是置信区间。不同群的矩阵表达式复杂度、等价关系数、文件体积不同，不能仅按最终分类数线性估算。内存竞争与系统负载可能进一步延长运行。47 号群的回读特别慢，因此建议预留 1 小时。

本次输出文件合计 2.55 GB。大文件位于 `recomputed_results/full_export_benchmark/`（已由 Git 忽略，不上传仓库）。
